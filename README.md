# Tic-Tac-Toe AI using Minimax Algorithm

## 📌 Project Overview

This project is a Tic-Tac-Toe game with an AI opponent developed using Python. The player competes against the computer, and the AI uses the Minimax algorithm to make optimal decisions.

This project was developed as part of my CodSoft Artificial Intelligence Internship – Task 2.

## 🎯 Objective

The main objective of this project is to implement an AI that can make intelligent decisions in a Tic-Tac-Toe game using the Minimax algorithm.

## ✨ Features

* Human player vs AI opponent
* AI uses the Minimax algorithm
* AI evaluates possible game moves and chooses the best one
* Detects winning combinations
* Detects draws
* Prevents invalid moves
* Handles invalid user input
* Simple command-line interface

## 🧠 How the AI Works

The AI uses the Minimax algorithm, a decision-making algorithm commonly used in two-player games.

The algorithm checks all possible moves and evaluates the possible outcomes. The AI tries to maximize its score, while the opponent is assumed to minimize the score. Based on these evaluations, the AI selects the best possible move.

This allows the AI to make strategic decisions instead of choosing moves randomly.

## 🛠️ Technologies Used

* Minimax Algorithm
* Command Line Interface

You can check by opening Command Prompt or Terminal and running:


The Tic-Tac-Toe game will start in the command-line interface.

## 🎮 How to Play

1. The human player plays as **X**.
2. The AI plays as **O**.
3. The board contains 9 positions.
4. Enter a number from **1 to 9** to select your position.
5. The AI will automatically calculate its best move using the Minimax algorithm.
6. The game continues until the human player wins, the AI wins, or the game ends in a draw.

### Board Positions

```text
1 | 2 | 3
---------
4 | 5 | 6
---------
7 | 8 | 9
```

For example, entering `5` places your mark in the center position.
