## Tic-Tac-Toe AI (Minimax Algorithm)

An unbeatable Tic-Tac-Toe game where the AI opponent uses the Minimax algorithm to always play optimally — it will never lose, only win or draw.

### Features
- Human (X) vs AI (O)
- AI evaluates all possible future moves using Minimax
- Detects win, loss, and draw conditions
